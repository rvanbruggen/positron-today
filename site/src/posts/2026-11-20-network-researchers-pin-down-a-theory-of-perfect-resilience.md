Here’s a fascinating step forward in understanding how computer networks can keep data moving when links fail. Researchers have now proved that exactly four minimal network structures prevent perfect resilience, where routers can still deliver packets despite any link failures that don’t cut off the destination entirely. The challenge is that routers must make quick decisions using only local information, without a global map of the network. So this result gives researchers a complete picture of which network structures can reliably route packets under those realistic constraints.
